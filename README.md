# Password Checker
A web-based tool to check the strength of passwords using Flask and zxcvbn. It also checks if your password has appeared in known data breaches using the Have I Been Pwned API.

## Live Demo
https://password-checker-i7t2.onrender.com

## Features
- Real-time password strength analysis (using zxcvbn)
- Checks password against public data breaches (Have I Been Pwned API)
- Suggestions to improve weak passwords
- Clean and simple UI

## Tech Stack
- Python
- Flask
- zxcvbn
- requests
- HTML/CSS

## Setup Instructions

1. Clone the repository:
   Navigate - cd Password-checker

2. Install dependencies:
   pip install -r requirements.txt

3. Run the Flask app:
   python app.py

4. Open your browser and go to:
   http://127.0.0.1:5000
